# Описание проекта для составления отклика / резюме (Prompt for AI)

### Контекст для генерации сопроводительного письма / отклика на вакансию:

**Название / Суть проекта:**
Кроссплатформенная система удаленного доступа и управления ПК (аналог AnyDesk / TeamViewer / RustDesk), написанная на **Go (Golang)** с использованием **gRPC** и **Fyne GUI**.

**Архитектура и компоненты проекта:**
1. **Client (Клиентское GUI-приложение):**
   - Графический интерфейс на **Fyne v2**.
   - Отображение потокового видео низкой задержки с удаленного ПК через пайплайн **FFmpeg** (`ffmpeg-go`).
   - Интерактивный оверлей для перехвата и передачи событий мыши (включая батчинг движения) и клавиатуры в реальном времени.
   - Менеджер файлов: удаленное дерево файловой системы с возможностью скачивания и загрузки файлов.
   - Встроенный интерактивный терминал (Remote PTY) для выполнения команд на удаленной машине.

2. **Server / Host Agent (Сервер/Хост-агент):**
   - Фоновый агент на удаленной машине (поддерживает GUI-панель и Headless-режим без GUI).
   - Захват экрана на базе библиотеки `kbinani/screenshot` и стриминг кадров через gRPC.
   - Эмуляция ввода мыши и клавиатуры на стороне операционной системы с использованием `robotgo`.
   - Управление виртуальным псевдотерминалом (PTY) через `go-winpty` (Windows PTY).
   - Гранулярная система разрешений (хост может настраивать доступ к мыши, клавиатуре, файловой системе и терминалу).

3. **Relay Server (Промежуточный прокси-сервер NAT Traversal):**
   - Высокопроизводительный TCP Relay-сервер для соединения клиентов и хостов, находящихся за NAT/Firewall без прямого IP.
   - Генерация запоминающихся человекочитаемых ID (например, `PlumPuffin`) для подключения.
   - Динамическая аллокация портов и проброс туннелей.
   - Аутентификация и защита сессий с хэшированием паролей `bcrypt`.

4. **Launcher (Единый лаунчер):**
   - GUI-приложение для выбора роли ("Become a Host" / "Connect to Remote PC"), настройки паролей, портов и прав доступа.

5. **Протоколы и Безопасность:**
   - **Protocol Buffers v3 & gRPC**: двунаправленный стриминг видео, ввода, файлов и терминала (`GetFeed`, `CommandStream`).
   - **Безопасность**: Защищенный TLS 1.3 / mTLS слой со встроенными сертификатами, безопасная передача данных.

**Стек технологий:**
- **Язык:** Go (Golang 1.23+)
- **Связь и протоколы:** gRPC, Protocol Buffers (Protobuf), TCP Relay Proxy, mTLS / TLS 1.3
- **GUI:** Fyne v2
- **Видео и мультимедиа:** FFmpeg, `u2takey/ffmpeg-go`, `kbinani/screenshot`
- **Системное программирование и автоматизация:** OS Automation (`robotgo`), PTY (`go-winpty`), WMI / Gopsutil
- **Безопасность:** `golang.org/x/crypto/bcrypt`, X.509 TLS Certificates
- **Инструменты:** Buf (Protobuf codegen), Go modules

---

### Ключевые навык и сильные стороны разработчика в этом проекте:
- Опыт разработки **сетевых систем на Go** с использованием **gRPC и Protobuf** (двунаправленный streaming).
- Понимание **микросервисной/клиент-серверной архитектуры** и обхода NAT (Relay TCP проксирование).
- Опыт работы с **многопоточностью (goroutines, channels, mutexes)** для обработки видеопотоков и ввода без задержек.
- Опыт интеграции с системным API (эмуляция ввода, PTY терминал, захват экрана, WMI).
- Навыки работы с **безопасностью** (mTLS, TLS 1.3, bcrypt).
- Опыт создания десктопных GUI-приложений на Go (библиотека Fyne).
